# 踩过的坑（按出现概率排序）

## 一、人格不像人

### 1. 回复永远很长、很客气

**根因**：人格里只有形容词（温柔、体贴），没有长度约束。
**修**：把统计出的句长写进规则（「将近一半的话不到四个字」），并把所有示例换成短句。

### 2. 回复「AI 味」重，像客服

**根因**（实测最常见的三个）：

- 上下文里残留着旧人格的回复 → 模型跟着学
- 示例写得太工整、带标点
- 没有「绝对不要」护栏

**修**：

```sql
delete from conversations;   -- 清掉旧上下文
```

再把 `max_turns` 调到 10 左右，示例全部改成无标点短句。

### 3. 加了重复示例，反而更死板

**现象**：想让她「说话多样」，于是把同一句配了三种回答放进示例 → 结果她每次都用其中某一种。

**结论**：**示例教的是「怎么说」，教不了「随机」**。
要随机就在代码里随机（每次注入一条「这次用 X 说法」的指令），别指望示例。

### 4. 冷淡的语气溢出到所有场合

**现象**：加了「不高兴就说『哦』」之后，连「在干嘛呢」都回「没什么」。

**修**：在人格里加一句边界——「冷淡只在他惹到你、或者你真的很累很难受的时候；平时该正常回」。

## 二、部署

### 5. Windows 打的 zip 在 Linux 解压失败

`Compress-Archive` 用反斜杠做路径分隔符，服务器解压出单文件。
**修**：用 Python 的 `zipfile`，`arcname` 显式用 `/`。

### 6. 插件装了但没生效

`install-upload` 成功 ≠ 已加载。看日志有没有 `Loading plugin xxx`。
没加载就重启容器（插件在启动时扫描目录）。

### 7. 重启容器后 QQ 掉线

`docker restart napcat` 会让 QQ 掉登录态（要重新扫码）。
`docker restart astrbot` **不影响** NapCat 的登录。

⚠️ 但连续快速重启 AstrBot 多次，NapCat 的反向 WS 客户端会卡死（日志停在「30 秒后尝试重新连接」）。
**修**：尽量避免短时间多次重启；真卡住了只能重启 napcat（掉登录）或等它自己恢复。

### 8. 改人格改了没反应

人格只在启动时加载 → 必须 `docker restart astrbot`。

## 三、插件与后台任务

### 9. 后台循环泄漏（最隐蔽的坑）

**现象**：反复热重载带 `asyncio.create_task` 的插件后，功能开始重复触发（比如主动搭话一分钟一次）。

**根因**：reload 只注销了 handler，**没有取消旧实例的 task**。

**修**：进程级代号（挂在 `astrbot.api` 模块上，而不是本模块——每次 reload 都是新模块对象）：

```python
import astrbot.api as _api
_api._my_gen = getattr(_api, "_my_gen", 0) + 1
self._gen = _api._my_gen

async def _loop(self):
    while True:
        if self._gen != getattr(_api, "_my_gen", 0):
            return          # 旧实例自己退出
        await asyncio.sleep(60)
        ...
```

验证方法：把间隔调到 1 分钟，数 60 秒内触发几次。**应该恰好 1 次。**

### 10. 插件导入失败但没提示

`Failed to import plugin xxx: name 're' is not defined` —— 缺 import 时插件整个不加载，
但面板里可能还显示「已激活」。**每次部署后都要看日志确认加载成功。**

## 四、外部数据源

### 11. B 站接口 412 风控

图片/视频信息接口对服务器 IP 返回 `412 Precondition Failed`。
**修**：带 `buvid3` cookie。**随机拼的 buvid 也会被拒**，要先向
`/x/frontend/finger/spi` 申请真实 `buvid3/buvid4`，再拿去请求。

### 12. B 站排行接口 -352

`ranking/v2` 对某些 IP 直接封。**改用 `popular`**（`/x/web-interface/popular?ps=20&pn=1`）。

### 13. 表情包搜索结果带水印 / 不相关

图片搜索引擎抓到的图质量参差。
**修**：文件名按情绪归类后人工过一遍，删掉不合适的；或在插件里提高门槛（只收 GIF / 小于 400KB）。

### 14. 微信密钥提取

- 需要微信**正在运行且已登录**
- 提取的是内存里的 `Config.Cipher`，微信一关可能就变了
- 多个数据目录时要显式指定 `--db-dir`

## 五、环境

### 15. 屏幕 125% 缩放导致自动化点击全偏

Windows DPI 缩放时，不同进程的坐标空间不一致，`SetCursorPos` 会偏。
**结论**：涉及浏览器自动化，优先用 **UI Automation 按名称找控件**，别用坐标点。

### 16. 从截图里读密钥会读错

OCR 肉眼校对也容易错（0/O、l/1）。
**修**：能点「复制」就点复制，读剪贴板。

### 17. PowerShell 5.1 把 .ps1 当 GBK 解析

含中文的脚本会报「数组索引表达式缺失」之类的怪错。
**修**：脚本存成 **UTF-8 带 BOM**，或者只用 ASCII。

### 18. 装 SDK 把主程序的依赖降级

`pip install` 某个 SDK 时连带把 `aiofiles` 降级，主程序直接起不来。
**修**：运维工具装到**独立 venv**，不要污染运行环境。
