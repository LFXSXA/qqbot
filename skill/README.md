# 用聊天记录，做一个会主动找你聊天的 AI 伙伴

> 把一段真实的聊天记录，变成一个像 TA 一样说话、有自己情绪、会主动联系你的 AI，跑在 QQ 上，24 小时在线。

---

## 你能得到什么

**一个活生生的 TA，而不是一个问答机器人。**

它和普通 AI 角色扮演的区别：

| | 普通 AI 角色 | 这个 |
|---|---|---|
| 说话方式 | 靠形容词猜（"温柔、可爱"） | 从真实记录**量**出来（句长、语气词、口头禅） |
| 情绪 | 没有，全靠你喂 | 有自己的心情、精力、今天发生的事，会主动说累 |
| 记忆 | 聊完就忘 | 记得你说过的承诺，忘了会提醒你 |
| 主动 | 你不说话就沉默 | 会自己找你，偶尔发条视频链接 |
| 吵架 | 只会哄你 | 知道上次哪里做错了，这次换更好的方式 |
| 表达 | 纯文字 | 文字 + 表情包 + 语音 |

## 你需要准备什么

| 东西 | 说明 |
|---|---|
| 聊天记录 | 你和 TA 的微信/QQ 导出（越多越好，最好一年以上） |
| 一台服务器 | 2 核 3.6G 内存就够，约几十块/月 |
| 一个 QQ 号 | 给小号登录，手机扫码确认一次 |
| 一个模型 API | DeepSeek 之类的（很便宜，几分钱/天） |
| 一点耐心 | 按流程走，全程约 1 小时 |

**不需要会编程。** 安装有脚本，配置有向导。

## 三步上手

### 第一步：准备记录

把聊天记录导出成文本，一行一条：

```
[2024-03-15 21:04] 她: 晚安
[2024-03-15 21:04] 我: 早点睡
```

微信导出用 [wechat-cli](https://github.com/latentide/wechat-extract-skill)，QQ 用漫游导出。

### 第二步：分析 + 写人设

```bash
# 自动统计 TA 的说话方式（句长、结尾字、口头禅）
python3 analyze_corpus.py chat.txt

# 自动挖出冲突、深情、和解片段，生成场景草稿
python3 mine_scenes.py chat.txt
```

拿着统计结果，照模板填人设。**人设不是写出来的，是量出来的。**

### 第三步：装插件

```bash
bash install.sh /AstrBot/data
python3 setup_wizard.py --data /AstrBot/data
```

向导问 5 个问题（QQ 号、人格文件、间隔、音色、表情概率），装完重启，按验收清单走一遍。

## 它能做什么

- 用 TA 的真实说话方式和你聊天
- 有自己的情绪状态，会主动说累、说心情不好
- 记得你的承诺和偏好
- 吵架、道歉、分手这些关键时刻，用"更好的方式"回应
- 表情包按情绪配（GIF 优先）
- 语音说话（4 种中文音色）
- 你发个视频链接，它就下载发给你
- 没人说话时主动找你，偶尔发视频链接
- 问它正经问题（买什么、怎么办），会联网搜索再回答

---

## 它不能做什么（请先看清楚）

| 需求 | 为什么不行 |
|---|---|
| TA 本人唱歌 | 语音合成唱不了；真歌声要 GPU 训练 |
| 一两句样本克隆音色 | 本机跑不动实时克隆，云端要另外付费 |
| 记住几百轮之前的所有细节 | 只存简短事实，超过上限淘汰 |
| 帮你订票、查订单、跨平台操作 | 没有工具调用 |
| 保证永远不说错话 | 模型会跑偏，只能压，压不干净 |

**它是一份"高度还原的陪伴"，不是真人，也不是万能助手。**

## 常见问题

**Q：要多少聊天记录才够？**
A：至少几千条。越多越好，因为要统计说话习惯，还要挖吵架、和好的片段。

**Q：能用在别的平台吗？**
A：目前是 QQ（NapCat）。微信/Telegram 需要另配适配器。

**Q：装完要维护吗？**
A：偶尔看下日志。B 站登录 cookie 会过期，过期了重扫一次码。

**Q：她会不会说错话、露馅？**
A：会。这是概率模型，靠规则压，压不干净。介意的话就别当真人。
